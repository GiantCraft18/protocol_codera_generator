💻 Протокол кодера — генератор постов

Локальный генератор публикаций для Telegram-канала «Протокол кодера». Помогает создавать, оформлять и подготавливать посты к публикации с помощью шаблонов и искусственного интеллекта через OpenRouter API.

✨ Возможности

- 🤖 ИИ через OpenRouter — генерация черновиков публикаций с помощью выбранной языковой модели.
- 📝 Шаблоны постов — подготовка гайдов, подборок, новостей и обучающих материалов.
- 📐 Настройка красной строки — выбор отступа абзацев для HTML и обычного текста.
- 🎨 Предпросмотр — просмотр оформления до публикации.
- 📋 Копирование — быстрое копирование HTML-кода и обычного текста.
- 📥 Экспорт — сохранение публикации в HTML-файл.
- 🏷️ Хэштеги — добавление тегов к публикациям.
- ⚙️ Настройка оформления — изменение темы, категории, стиля и призыва к действию.

🚀 Запуск

1. Скачай и распакуй архив проекта.
2. Открой папку проекта.
3. Запусти "index.html" в браузере.
4. Заполни поля и нажми кнопку сборки поста.

Способ 2. Через Visual Studio Code

1. Открой папку проекта в Visual Studio Code.
2. При желании установи расширение Live Server.
3. Нажми правой кнопкой мыши на "index.html".
4. Выбери Open with Live Server.
5. Генерируй и редактируй публикации в браузере.

🤖 Подключение OpenRouter

OpenRouter позволяет обращаться к языковым моделям через единый API.

Шаг 1. Создай API-ключ

1. Перейди на "OpenRouter" (https://openrouter.ai/).
2. Войди в аккаунт.
3. Открой раздел управления API-ключами: "OpenRouter — API Keys" (https://openrouter.ai/settings/keys).
4. Создай ключ и скопируй его.

Шаг 2. Настрой генератор

В блоке «ИИ через OpenRouter»:

1. Вставь API-ключ.
2. Укажи название доступной модели, например "openai/gpt-4o-mini".
3. Настрой инструкцию для ИИ.
4. Заполни тему и исходные тезисы.
5. Нажми «Создать текст с ИИ».

ИИ подготовит текст, который появится в поле основного материала. После этого можно изменить отступы, посмотреть предпросмотр и скопировать результат.

«Доступность модели, стоимость запросов и необходимость пополнения баланса зависят от настроек аккаунта OpenRouter.»

📐 Настройка красной строки

В генераторе можно выбрать размер отступа:

- 0 — без отступа.
- 1 em — небольшой отступ.
- 1,25 em — стандартный вариант.
- 2 em — увеличенный отступ.
- Свой размер — пользовательское значение.
- 4 пробела — отступ для обычного текста.

Для HTML применяется CSS-свойство "text-indent". В обычном тексте отступ формируется пробелами.

Примечание: Telegram и сторонние боты для публикации могут по-разному обрабатывать HTML-разметку и начальные пробелы. Проверяй итоговый вид в целевом клиенте перед массовой публикацией.

🔐 Безопасность

- Не публикуй API-ключ в открытом доступе.
- Не вставляй ключ непосредственно в исходный код "index.html".
- Не отправляй ключ другим людям.
- Не используй общий публичный компьютер для работы с секретными ключами.
- При подозрении на утечку отзови ключ в настройках OpenRouter и создай новый.
- Не используй клиентский вариант как публичный сервис для других пользователей.

В текущем варианте ключ вводится в интерфейсе и хранится в памяти открытой вкладки. Запросы отправляются напрямую в OpenRouter. Это не полноценная серверная защита: при использовании публичного сайта рекомендуется перенести запросы к API на собственный сервер и хранить ключ в переменных окружения.

⚠️ Ограничения

- Генератор не публикует посты в Telegram автоматически.
- Для работы ИИ требуется подключение к интернету.
- Ответы ИИ могут содержать ошибки или неподтверждённые сведения.
- Наличие API-ключа не гарантирует бесплатный доступ к модели.
- Обычные шаблоны форматируют введённые тезисы, но сами по себе не проверяют достоверность фактов.

Перед публикацией проверяй технические инструкции, команды, новости и ссылки.
